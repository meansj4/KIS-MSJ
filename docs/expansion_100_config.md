# 현재 종목 구성과 위험한도

파일명은 과거 100종목 확장 작업의 링크 호환을 위해 유지하지만, 내용은 2026-08-04 현재 설정 기준이다.

- 설정 종목: 232개
- 활성 종목: 232개
- `buy_blocked=true`: 72개
- `retire_after_exit=true`: 72개
- 최대 활성종목: 300개
- 전체 최대 OPEN LOT: 3,000개
- 전체 최대 투자액: 200,000,000원
- 일일 신규매수 최대: 300건
- 일일 신규/최초매수 금액 최대: 30,000,000원
- 최소 주문가능 현금: 30,000원

72개 청산예정 종목은 기존 LOT의 정상·recovery 매도는 허용하지만 신규·추가·재진입 매수를 하지 않는다. OPEN LOT이 0이 되면 `TRADE_STOPPED_AFTER_EXIT`로 전환된다.

종목 수를 늘릴 때는 설정 개수만 보지 말고 실제 동시 보유, 가격대별 종목 최대금액 합, 테마 집중, API 루프시간, 일일 주문한도를 함께 검증한다. `scripts/benchmark_loop.py`와 전체 테스트를 실행하고 실계좌 설정 변경 전 백업을 남긴다.

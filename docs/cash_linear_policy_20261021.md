# 주문가능금액 기반 매수·매도 정책

2026-10-21 사용자 지정 규칙. 과거 수익 최적화 결과를 의미하지 않는다.

## 매도 목표와 decay

기본 매도 목표율 = `max(주문가능금액, 0) / 200,000,000 × 0.40`.

각 LOT의 최종 목표율 = `기본 목표율 − 원래 매수시각부터의 보유 주수 × 해당 종목의 현재 남은 LOT 수 × 0.001`.

주말을 포함해 경과시간에 비례하며, LOT 수가 바뀌면 원래 보유기간 전체에 새 개수를 적용한다. 12 LOT이면 주당 1.2%p 차감한다. 목표율은 음수가 될 수 있다.

주문가능금액 1,200만원 이하에서는 해당 종목의 가장 오래된 LOT을 우선 매도한다. 이때 목표 도달은 기다리지 않고 현재가에 공통 매도 할인율 0.5%를 적용한 호가 단위 지정가를 사용한다. 이 규칙이 음수 decay 목표보다 우선한다.

저현금이 아닌 구간에서 음수 목표에 따른 손실 매도 조건이 성립하면 해당 종목의 최고 매입가 LOT을 정리한다. 지정가는 신호 LOT의 목표 지정가를 유지한다. 기존 심각손실 회복 등 별도 위험·거래 차단 규칙은 함께 적용한다.

## 매수 기준

매수 하락률 = `clamp(0.40 × (1 − max(주문가능금액, 0) / 200,000,000), 0, 0.40)`.

| 주문가능금액 | 기본 매도 목표 | 매수 하락률 |
|---:|---:|---:|
| 0원 | 0% | −40% |
| 1천만원 | +2% | −38% |
| 5천만원 | +10% | −30% |
| 1억원 | +20% | −20% |
| 2억원 | +40% | 0% |

사용자가 average도 수량 가중평균으로 선택했으므로 `min(VWAP, average)`는 같은 가중평단이다. 남아 있는 LOT의 `매입단가 × 잔여수량` 합을 잔여수량 합으로 나눈다. 기존 PLUS/MINUS별 VWAP·중앙값 선택과 고정 LOT 단계별 낙폭은 새 정책에서 매수 가격 기준으로 사용하지 않는다.

추가매수는 기준 평단에서 위 하락률만큼 낮은 가격 이하에서만 가능하다. 수학적 한도를 넘지 않도록 지정가는 호가 단위로 내림한다. 실제 제출가는 전략 한도와 현재가 근처 매수 지정가 중 낮은 값이다.

전량 매도 후 재진입에도 같은 가격 조건을 적용한다. 전량청산 직전 남은 재고의 가중평단과 시각을 저장하며, 종전의 60 LOT분 주문가능금액 조건도 함께 충족해야 한다. 기존 대기 종목은 원장의 최종 매도 원가로 확실히 복원할 수 있을 때만 기준을 보완한다. 근거가 없으면 임의의 현재가로 대체하지 않고 재진입을 차단한다.

보유 이력이 없는 최초 매수에는 기준 평단이 없으므로 기존 최초 진입·위험·금액 한도 규칙을 유지한다. 수동 주문도 기존 별도 경로를 유지한다.

## 현금 갱신과 보호

체결·주문 후 계좌 현금 캐시를 무효화하고 다음 판단에 새 금액을 사용한다. 주문 직전 가격 안정성 검사를 마친 뒤 주문가능금액을 다시 조회하고 매수·매도 행동 전체를 재계산한다. 자동 추가매수와 재진입은 주문 제출 계층에서도 신선한 현금과 저장 재고를 기준으로 지정가를 다시 검사한다.

이전 매도가보다 항상 낮게 재진입한다는 별도 조건은 없다. 보존한 매입 평단이 기준이므로 손실 매도 이후에는 새 가격 조건을 만족하면서도 직전 매도가보다 높은 재진입이 가능하다.

UI 장애 수정과 이 정책 변경은 별개다. UI에는 버전별 캐시 누적 제거, 캐시 상한, 중복 조회 계산 공유, 인덱스 조회, 통신 제한시간과 복구, 이전 화면 응답 차단, Windows 동일 포트 중복 실행 방지가 적용되어 있다.

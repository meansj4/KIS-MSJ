# 포트폴리오 대시보드

대시보드는 현재 포지션, LOT, 주문·체결 DB를 결합해 운용상태를 보여준다. 주요 목적은 실시간 계좌원장 대체가 아니라 전략의 노출·손익·회전·차단상태를 한 화면에서 점검하는 것이다.

## 주요 지표

- 투자원금 및 현재 평가액
- 실현·미실현·합산 손익
- OPEN LOT, 활성 종목, `REVIEW_REQUIRED`, `SYNC_REQUIRED` 수
- 종목·테마·가격대별 집중도
- 이익실현, cleanup, deep-loss recovery 등 매도사유별 결과
- 종목 상세의 LOT 목표가, 재진입 상태, 심각손실 recovery 상태

예상 실현손익은 매도대금의 `estimated_fee_tax_pct=0.21%`를 비용으로 차감한다. 이는 비교용 추정치이며 실제 계좌 수수료 우대, 거래세, 체결별 원단위 처리와 다를 수 있다.

## 이력 그래프 해석

그래프 데이터는 저장된 LOT·fills·가격을 이용해 과거를 재구성한다. 과거 날짜별 KIS 예수금과 총자산 스냅샷이 지속 저장된 원장은 아니다. 다음 상황에서는 실제 계좌 총자산과 차이가 날 수 있다.

- 전략 시작 전 보유분 또는 누락 체결
- 입출금·배당·세금·수수료의 별도 정산
- 해당 날짜 가격 부재와 대체가격 사용
- 부분체결 또는 사후 정합성 보정

따라서 그래프의 총손익과 두 날짜의 증권사 총자산 차이를 동일한 값으로 간주하지 않는다.

## 내보내기

기간 선택 후 JSON 또는 CSV를 저장할 수 있다. JSON은 지표 정의와 데이터 한계를 함께 전달하므로 외부 AI 분석에 권장한다. CSV는 표 계산과 별도 차트 작성에 적합하다. 외부 서비스에 업로드하기 전에 계좌번호·주문번호·개인정보 포함 여부를 확인한다.

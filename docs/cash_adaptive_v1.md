# 현금 연동 보호 기능 v1 — 수정 방향 확정안

작성일: 2026-10-15. 상태: 구현 전 설계. 운영 코드·설정·주문은 이번 작업에서 변경하지 않는다. 수치는 수익 최적값이 아니라 초기 보호 기준이다.

목표: 현금이 부족할 때 매수 조건을 강화하고, 비용 후 이익이 남는 익절 조건을 완화한다. 현금 여유가 생겨도 기존 전략보다 매수를 쉽게 하거나 매도 목표를 높이지 않는다.

## 1. 현금 비율과 조절식

- E: 최신 증권사 계좌 평가자산(total_asset). 설정의 투자상한2억원을 분모로 사용하지 않는다.
- C: 즉시 주문가능 현금에서 최신 계좌조회 이후 발생한 미반영 예약만 조정한 실효 가용현금. 브로커가 이미 차감한 미체결 주문은 다시 빼지 않는다. 신용·미수로 가용액을 늘리지 않는다.
- 현금 비율 r=C/E. E가 없거나 0 이하이거나 계좌 조회·예약 상태가 불명확하면 BUY를 보류한다. 기존 SELL 평가까지 중단하지 않는다.
- 긴축 정도 p=clamp((0.20-r)/0.10, 0, 1).

| 현금 비율 | 추가매수·조건부 재진입 하락폭 | 익절 목표 보정 | 모든 BUY 공통 제한 |
|---|---|---|---|
| 20% 이상 | 기존값 | 기존값 | 공통 예산 검사 |
| 10% 초과~20% 미만 | 기존값 + p×1%p | 기존 유효 목표 - p×1%p | 공통 예산 검사 |
| 10% 이하 | BUY 보류 | 기존 유효 목표 - 1%p | 신규·추가·재진입 BUY 보류 |

예: 현금15%이면 p=0.5. 추가매수4% 하락 조건은4.5%, 익절3% 목표는2.5%로 조절한다. 현금10% 이하에서는 BUY를 보류하고, 양수 익절3% 목표는2%로 완화한다. 수수료·세금 및 최종 지정가 하한이 우선한다.

BUY는 최종 주문 후 현금비율로 조건을 재검사하고 더 엄격한 조건을 적용한다. 새로운 사이클의 최초 진입처럼 가격 하락 anchor가 없는 BUY에는 임의의 할인 기준을 만들지 않고 공통 예산을 적용한다. timeout 강제 재진입도 공통 예산을 우회할 수 없다.

10% 이하로 BUY가 보류된 뒤에는 현금12% 이상에서만 재개 가능 상태로 전환한다. 상태를 저장해 재시작으로 이 조건이 사라지지 않게 한다. 재개 가능 상태가 되어도 runtime pause·종목 buy_blocked·다른 기존 위험 제한은 해제하지 않는다.

## 2. 모든 BUY에 적용할 필수 예산

- 하한: 주문 후 실효 가용현금 >= max(현재 최소현금 설정, 최신 계좌 평가자산의10%).
- 하루 총 BUY 한도: 당일 첫 유효 계좌 평가자산의2%. 최초·추가·모든 재진입·수동 매수·시간외/다른 거래소 주문을 계좌 하나로 합산한다. 장중 자산 증가로 한도가 늘어나지 않는다.
- 당일 실제 BUY 체결대금 + 아직 체결되지 않은 BUY 예약금 + 새 주문 예약금으로 검사한다. 매도는 당일 총 BUY 예산을 복원하지 않는다. 확정 취소·명확한 거절의 미체결 예약만 해제하며, 접수 불명·취소 불명은 유지한다.
- 수량×최종 지정가와 비용 버퍼로 검사한다. 같은 snapshot의 현금을 여러 주문에 중복 배정하지 않는다. 증권사 주문가능현금과 로컬 예약을 시점별로 대사한다.
- 기존 종목·전체 원가/LOT 상한도 새 주문과 미체결 예약을 포함해 검사한다. 예산이 모자라면 이번 BUY를 보류한다. 반 LOT을 만들거나 1주를 강제로 올림해 예산을 넘기지 않는다.
- 적용 당일 이미 새 한도를 초과했다면 추가 BUY를 보류한다. 기존 체결을 되돌리거나 이 설정만으로 미체결 주문을 자동 취소하지 않는다. 미체결 주문 처리는 별도로 점검한다.

## 3. 매도 완화의 범위

- 기존 LOT의 매입원가·매입일·기본 목표·cycle sizing을 보존한다. 기존 유효 목표를 계산한 뒤 현금 보정치를 일시적으로 적용한다. 매 루프마다 기본 목표를 덮어쓰거나 보정치를 누적하지 않는다.
- 현금 보호를 위해 새로 완화하는 익절은 최종 실제 지정가에서 추정 비용을 차감해도 양수 이익이 남는 가격 이상으로 제한한다. 호가단위 올림과 최종 주문 직전 검사를 적용한다. 현재가로만 이익을 판정하지 않는다.
- 기존 음수 decay 목표를 이 기능 때문에 더 낮추지 않는다. 원래 손실 정리·deep-loss 규칙은 별도로 유지한다. 현금 부족 자체가 새 손절 사유가 되지 않는다.
- 익절 수량·부분매도 비율·deep-loss 기준은 v1에서 변경하지 않는다.

## 4. 교체매도와 기존 플래그

- 다른 매수의 자금 마련만을 위한 CASH_SHORTFALL_ROTATION은 v1 운용에서 사용하지 않는다. 현금 부족은 BUY 보류로 처리한다.
- 구현 전에 durable order intent·중복 제출 방지를 교체매도 활성 플래그에서 분리해 항상 유지한다. 플래그 하나만 끄면서 주문 안전장치가 함께 꺼지게 하지 않는다. 기존 회전 후 재매수 가격 보호도 별도 정책으로 보존한다.
- 현재 reentry_paused=true는 그대로 유지한다. 현금 회복으로 자동 해제하지 않는다. buy_paused 및 개별 종목 매수 차단도 다른 모듈이 임의 해제하지 않는다.
- 대규모 종목 교체·강제 축소·Plan B 목표 이관은 이번 수정 범위에 넣지 않는다.

## 5. 구현과 검증 순서

1. 공통 BUY 예약·예산·현금 하한과 교체매도 중단을 먼저 구현한다. BUY가 막혀도 기존 SELL은 평가되게 한다.
2. 현금에 따른 BUY 하락폭·익절 목표 보정을 추가한다.
3. 동일한 기존 LOT·원가·현금으로 주문 없는 비교를 수행한다. 원래 방식 / 예산 보호만 / 예산+BUY 조절 / 예산+BUY+SELL 조절을 분리해 평가한다.
4. 현금 하한 위반0, 미체결 이중배정0, 최종 지정가 기준 새 익절의 순손실0, pause 우회0, 재시작 후 예약·상태 복원을 필수 통과 기준으로 둔다. 데이터 불명 시 BUY 보류도 확인한다.
5. 비용 후 기간 총손익, 최저현금, 최대낙폭, 순투입, 미청산 원금을 함께 비교한다. 모든 기간 수익 우월성을 안전 기능의 유일한 채택 조건으로 삼지 않는다. 소액 운용 재개는 결과와 현재 계좌 상태를 검토한 뒤 별도 결정한다.

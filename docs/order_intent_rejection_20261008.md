현재 경고 5건은 NAVER(035420), HD현대건설기계(267270), SK텔레콤(017670), 엔씨소프트(036570), 롯데웰푸드(280360)의 매수 요청이다. 09:10~09:57 증권사 응답은 모두 APBK0952(주문가능금액 초과), rt_cd=7이었다. 주문 접수 불명 상태가 아니라 명시적 거절이다.

OrderManager의 세션 주문 예외 처리가 rt_cd=1만 거절로 판단하여 rt_cd=7을 submission_outcome_unknown으로 저장하고 재주문 방지 예약을 유지했다. 명시적 API 거절 응답의 1/7을 모두 처리하도록 수정했다. HTTP/네트워크 오류는 기존대로 접수 불명 상태를 유지한다.

복구 스크립트 tmp/repair_rejected_intents_20261008.py는 종목과 요청 시각(5초 이내)을 로그에 대조하고 단일 트랜잭션으로 해당 5건만 REJECTED로 변경했다. 변경 전 주문 전체와 근거 로그는 reports/order_intent_repair_20261008.json에 보존했다. 체결, LOT, 잔고는 수정하지 않았다.

UI 주문 경고도 미해결 INTENT에만 표시하도록 수정했다. 완료된 거절 예약에는 원장 복구 경고를 표시하지 않는다.

사용자 요청에 따라 자동매매 봇은 정지 상태로 유지한다. 코드 수정은 다음 봇/UI 시작 시 적용된다. 실행 중 UI의 상태 API에서 미해결 주문 수 0을 확인했다.

이 수정은 주문가능금액 부족 자체를 해소하지 않는다. 실제 주문가능금액에 대한 증권사 거절은 계속 정상적인 거절로 기록된다.

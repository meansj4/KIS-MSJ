# 현재 자동매매 전략

기준일은 2026-08-04이며 실운영 JSON과 현재 코드 기준이다.

## 1. 사이클과 LOT 크기

`lot_sizing_mode=cycle_locked_by_entry_price`이다. 최초 진입가격이 속한 가격대에서 `lot_unit_amount`와 `max_symbol_amount`를 고르고, 해당 보유 사이클이 끝날 때까지 고정한다. 주문수량은 LOT 금액을 현재 주문가격으로 나눈 정수 수량이며 최소 주문 가능 수량과 위험한도를 함께 확인한다.

매수는 현금·일일 신규매수·총 투자액·전체 LOT·API 오류·동기화·종목 상태 제한을 모두 통과해야 한다. `buy_blocked`인 종목은 모든 자동매수가 차단되지만 매도는 계속된다.

## 3. 매도

`PROFIT_TAKE`는 각 LOT의 유효 목표가 도달 시 발생한다. 예상 순손익에는 매도금액의 0.21% 비용을 반영한다. 고투입 구간에서는 `high_exposure_partial_sell_pct=50` 정책이 적용될 수 있다. 실제 DB 반영은 주문 요청이 아니라 체결 수량 기준이다.

기본 지정가는 매수 현재가 +0.3%, 매도 현재가 -0.5%를 호가단위로 보정한 가격이다. `DEEP_LOSS_RECOVERY_SELL`도 전략이 가격을 직접 고정하지 않고 주문관리자에 위임하므로 같은 매도 markdown을 사용한다.

`cleanup_enabled=false`이므로 일반 cleanup 매도는 현재 비활성이다.

## 4. 심각손실 recovery

완료된 일봉 종가가 LOT 매수가 대비 -40% 이하가 된 최초 날짜에 추적을 시작한다.

1. 추적 시작일과 이후의 최저 완료 종가를 DB에 저장한다.
2. 최초 요구 반등률은 최저 종가 대비 +10%이다.
3. 요구 반등률은 30 캘린더일 동안 선형으로 0%까지 감소한다.
4. 현재가가 `최저 종가 × (1 + 현재 요구 반등률)` 이상이면 LOT 전량을 매도한다.
5. 30일째에는 가격과 관계없이 강제 매도한다.

추적 시작 후 손익률이 -40% 위로 올라가도 추적 상태는 해제하지 않는다. 동일 종목에 여러 대상 LOT이 있으면 오래된 LOT부터 평가하며 일일 개수 제한은 없다. 다만 같은 종목의 미체결 주문 중복 방지 때문에 주문은 순차적으로 진행된다. 이 매도는 `REVIEW_REQUIRED` 상태에서도 허용된다.

## 5. 전량매도 후 재진입

이익실현으로 OPEN LOT이 0이 되면 `WAIT_REENTRY`로 전환한다. 일반 재진입은 매도 사이클의 VWAP과 중앙값 중 낮은 앵커에서 기본 -4%, trailing 재진입은 높은 앵커 대비 +5% 상승 활성화 후 고점에서 -10% 조정을 본다. 두 문턱은 30 캘린더일 동안 0%까지 완화되며, 최소 대기 60분과 매수 후 쿨다운 60분이 있다. trailing 재진입은 하루 최대 1회다. 30일 timeout 강제 재진입은 새 사이클로 시작한다.

`retire_after_exit` 종목은 재진입하지 않고 `TRADE_STOPPED_AFTER_EXIT`가 된다.

## 6. 검토·차단 상태

현재 대표적인 `REVIEW_REQUIRED` 원인은 종목 전체 평가손실 -20% 이하, 동기화 불일치, 위험한도 및 LOT 구조 문제다. 오래 보유했다는 사실만으로 검토상태가 되던 `stale_lot_review_age` 조건은 제거됐다. stale LOT 표시는 손실 -15% 이하, 8주 이상, 기준가격과 -10% 이상 괴리라는 정리 후보 정보이며 그 자체가 장기보유 검토 트리거는 아니다.

# 시장데이터 수집과 활용

```powershell
.\.venv\Scripts\python.exe scripts\collect_market_data.py --help
```

시장데이터는 전략 분석과 완료 일봉 기반 조건에 사용한다. 현재가와 완료 일봉을 구분해야 한다. 심각손실 recovery는 완료된 일봉 종가로 추적을 시작하고 최저점을 갱신하지만, 반등 매도 충족 여부는 장중 현재가로 판단한다.

수집 시 종목코드, 거래일, 가격 조정 여부, 결측일을 보존한다. 휴장일은 데이터 누락이 아니며 recovery 경과일은 거래일이 아니라 캘린더일이다. 오늘 진행 중인 봉을 완료 종가로 저장하지 않는다.

대량 수집은 장중 봇 API 호출과 경쟁하지 않도록 별도 시간에 수행한다. 수집 실패를 0원 가격으로 대체하지 말고 결측으로 유지한다. 분석 결과를 설정에 반영하기 전에 dry-run과 테스트를 거친다.

# 예수금 여유 기준 재진입

2026-10-16 요청에 따라 운영 재진입 정책을 `cash_capacity_oldest`로 바꾼다. 아래 수치는 2026-10-17 확장 튜닝의 최종 선정값(`p_e6060e058aa7`)이며, 선정 근거와 설정 적용 기록은 [확장 튜닝 보고서](../reports/expanded_tuning_20261017/report.md)를 참조한다. 기존 NORMAL/TRAILING 가격 조건, 재진입 decay, 최소 대기시간, 일일 trailing 횟수, 재진입 후 추가매수 쿨다운, 30일 timeout 강제 재진입은 이 정책에서 사용하지 않는다. **매도 목표수익률의 age decay는 현재 종목 OPEN LOT 하나당 주간 0.05%p로 계산**하며, 각 LOT의 원래 매입일을 유지한다. 재진입은 한국시간 **2026-10-19 월요일부터 자동 재개**하도록 예약한다.

## 대기 순서와 현금 조건

1. OPEN LOT과 보유수량이 없는 `WAIT_REENTRY` 종목을 대기 시작시각(`exit_time`)이 오래된 순서로 검토한다. 같은 시각이면 종목코드 순서를 사용한다.
2. 현재 진입가격에 해당하는 가격대에서 **새 사이클의 1 LOT 금액**을 계산한다. 과거 사이클에 잠겼던 LOT 금액은 사용하지 않는다.
3. 주문 전 최신 주문가능현금이 `1 LOT 금액 × reentry_cash_lot_multiple` 이상인지 확인한다. 운영 배수는 **60**이다.
4. 충족하면 **1 LOT만** 매수해 새 사이클을 시작한다. 60 LOT을 한꺼번에 매수하는 규칙이 아니다.
5. 다음 종목은 앞선 주문의 영향을 반영한 현금으로 다시 판단한다. 현금이 부족하거나 매수 제한에 걸린 종목은 보류하고 이후 종목을 검토한다.

예를 들어 새 사이클의 1 LOT 금액이 22만5천원인 종목은 매수 전 주문가능현금이 명목상 **1,350만원** 이상이어야 한다. 기준 예산 22만5천원을 매수금액으로 쓰는 단순 계산에서는 1,327만5천원이 남는다. 이 규칙은 **매수 전 60 LOT 규모의 여유를 확인**하는 것이며, 매수 후에도 60 LOT 금액을 별도로 남기는 규칙은 아니다. 실제 매수수량은 기존의 정수 주식수 계산을 사용하므로 체결 후 잔액은 실제 체결금액과 주문 예약금을 반영해 갱신한다.

최종 주문 직전에는 지정가·정수 주식수를 반영한 실제 주문금액도 검사한다. `새 LOT 금액`과 `수량 × 최종 지정가` 중 큰 금액의 60배가 필요하며, 공통 제출 경로에서는 지정가가 속한 가격대의 LOT 금액도 확인한다. 호가 가산이나 가격대 경계 때문에 명목 LOT 금액의 60배보다 현금이 조금 더 필요할 수 있다.

대기 시작시각이 없거나 미래 시각이면 순서를 임의로 추정하지 않고 재진입을 보류한다. 종목 중지·교체대기·위험·동기화·미체결·주문중복 제한과 런타임 일시정지는 계속 적용한다. 미체결 매수의 자금이 아직 정산되지 않은 상태에서 다음 재진입을 중복 실행하지 않는다. 현금 부족을 이유로 다른 종목을 강제 매도해 재진입 자금을 마련하지 않는다.

## 주문 후 현금과 매도 목표 갱신

기준 현금은 기존 예수금 비례 매도 정책과 동일한 `AccountSnapshot.cash_available`, 즉 KIS의 즉시 주문가능한 미수 없는 현금이다. 가상으로 늘린 현금이나 아직 체결되지 않은 매도대금은 재진입 자금으로 사용하지 않는다.

재진입을 포함한 매수·매도 주문 후 계좌 snapshot 캐시를 무효화한다. 다음 주문 판단 전 최신 현금을 조회해 재진입 조건과 모든 OPEN LOT의 현금 비례 목표수익률을 다시 계산한다.

```
공통 기본 목표수익률 = max(0, 주문가능현금) / 200,000,000 × 0.0072
현재 종목의 주간 감소폭 = 현재 OPEN LOT 수 × 0.0005
LOT별 유효 목표수익률 = 공통 기본 목표수익률 - 해당 LOT의 보유 주수 × 현재 종목의 주간 감소폭
재진입 필요 현금(명목 기준) = 현재 가격대의 새 사이클 1 LOT 금액 × 60
```

## 설정과 UI

- `strategy.reentry_policy`: 운영값 `cash_capacity_oldest`.
- `strategy.reentry_cash_lot_multiple`: 운영값 `60`.
- `strategy.reentry_start_date`: 운영값 `2026-10-19`. 이 날짜 전에는 현금 여유 재진입을 허용하지 않는다.
- `runtime_control.json`은 `reentry_paused=true`, `reentry_resume_on=2026-10-19`로 자동 재개를 예약한다. 새 코드의 런타임 로더는 한국시간 예약일 전에는 차단하고, 예약일부터 유효 `reentry_paused=false`를 반환한다. 저장된 차단값은 유지하여 이전 버전 실행 프로세스에서 금요일에 즉시 재진입하는 일을 막는다. 사용자가 UI에서 재진입 일시정지 또는 전체 재개를 직접 조작하면 예약을 취소하고 해당 명시적 설정을 따른다.
- 봇과 UI가 새 코드를 로드한 이후 적용된다. 실행 중인 이전 버전에는 소스 변경만으로 반영되지 않는다.
- UI는 재진입 시작일·자동 재개 예약일·현재 유효 일시정지를 표시한다. 봇 로그에 남은 최근 현금으로 필요 현금과 조건 충족 여부를 표시하며 직접 계좌 API나 주문 API를 호출하지 않는다. 현금이 없거나 오래되었으면 미확인으로 표시한다.
- 판단 미리보기는 같은 현금 snapshot을 사용한 종목별 참고 후보다. 실제 주문에서는 오래된 대기 순서, 미체결 주문, 감소한 현금과 런타임 차단을 다시 검사한다.

이전 설정과의 호환용 기본값 `legacy_price`에서는 종전 재진입 규칙을 사용한다. 운영 정책에서는 종전 가격·decay·timeout 설정값을 재진입 판단에 사용하지 않는다. 기존 LOT·position·체결 이력은 초기화하지 않는다.

## 함께 선정한 운영값과 이력

- 현금 2억원의 decay 전 목표는 0.72%, 현금 0원은 0%이며 상한 없이 선형 계산한다. 저현금 최고원가 LOT 정리 기준은 1,200만원 이하다. [현금 연동 매도 정책](cash_target_profit.md)에 호가 올림 예시와 세부 매도 순서가 있다.
- 현재 12 OPEN LOT의 주간 감소폭은 0.6%p이며, 현금 0원에서 5주 보유한 LOT의 유효 목표는 -3%다.
- 추가매수 하락률은 6단계 모두 8.8%다. 사이클 LOT 금액과 투자상한은 기존 값을 유지한다.
- 일반 수익 매도는 종목 보유원가 60만원 초과에서 50% 분할 매도를 적용한다. 독립적인 deep-loss recovery의 초기 반등 목표는 15%, 최대 회복 대기는 60일이다. 재진입 방식과 별개인 매도 설정이며 [확장 튜닝 보고서](../reports/expanded_tuning_20261017/report.md)에 근거를 기록한다.

기존 최초 입력값은 현금 2억원의 목표 50%, 저현금 기준 500만원, 재진입 여유 30 LOT, OPEN LOT당 주간 decay 0.1%p였다. 현재 설명과 혼용하지 않는다. LOT 수 decay·재진입 예약 변경 직전의 `reports/lot_count_decay_20261019/`와 최초 현금 매도 정책의 `reports/cash_target_profit_20261019/` 백업은 보존하며, 확장 튜닝 직전 설정·runtime 원본은 `reports/expanded_tuning_20261017/frozen_before/`에 있다.

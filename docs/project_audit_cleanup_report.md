# 문서·구조 감사 보고서

기준일: 2026-08-04

## 이번 정리 결과

모든 Markdown 문서를 현재 코드와 실운영 JSON 기준으로 재작성했다. 과거 날짜의 작업일지, 이미 제거된 설정, 당시 종목 수와 임시 운영수치를 권위 있는 현재 설명에서 제거했다. 기존 파일명은 외부 링크 호환을 위해 유지했다.

현재 문서가 반영하는 주요 변경은 다음과 같다.

- 7일 고정 deep-loss timeout을 30일 반등 recovery로 교체
- `stale_lot_review_age` 장기보유 검토조건 제거
- `buy_blocked`와 `retire_after_exit` 분리 설명
- UI 그래프 JSON/CSV export와 재구성 데이터 한계 명시
- 완료 일봉 bulk cache, bulk DB save, 장외 루프 최적화 반영
- 현재 232종목/72 청산예정 및 최신 위험한도 반영
- 비용 추정률 0.21%, 주문 가격 보정값 반영

## 권위 순서

1. 실행 중인 프로세스가 실제 로드한 설정과 상태
2. 현재 소스코드와 `config/lot_auto_trader.json`
3. SQLite 주문·체결·LOT 데이터
4. Markdown 문서

문서는 운영 이해를 돕지만 실행 상태를 증명하지 않는다. 코드 변경 후 프로세스를 재시작하지 않았다면 문서와 디스크 코드가 최신이어도 실행 중 봇은 이전 로직일 수 있다.

## 유지관리

전략 키, UI 탭, DB schema, 운영 종목·위험한도가 바뀌면 같은 변경에서 README와 관련 문서를 함께 수정한다. 제거된 키가 문서에 남지 않았는지 `rg`로 검색하고 전체 테스트를 실행한다.
